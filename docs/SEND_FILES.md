# What to send & where it goes in the site

The site skeleton is built. Every placeholder ("coming soon" boxes, sample plots)
is replaced by your real files. All content lives in two files:

- `src/data/project.ts` — project details, villa types, tours, images, videos
- `src/data/plots.ts` — every villa plot on the master plan

Media files go in `public/media/`.

## Checklist

| # | Send this | Format | Used on |
|---|---|---|---|
| 1 | **Master plan / layout** | PDF, DWG, or high-res JPG/PNG | Master Plan page — every plot traced into a clickable shape |
| 2 | **Villa list** (one row per villa) | Excel / Google Sheet: Villa No, Type (267 / 567 / 600), Facing, Status, Price, Corner | Master Plan colours, filters, villa popup |
| 3 | **Villa tours for 267, 567, 600** | Link (Matterport / Kuula / YouTube / other) **or** the video/360 files | Villa pages → "Villa tour" |
| 4 | **Floor plans** for each villa type | PDF or JPG/PNG, each floor | Villa pages → "Floor plans" |
| 5 | **Villa images** (exterior + interior renders) | JPG/PNG, ≥1920px wide | Home cards, villa pages, gallery |
| 6 | **Videos** (walkthrough, drone, ads) | MP4 or YouTube links | Home hero video, Gallery |
| 7 | **Logo & brand colours** | SVG/PNG + colour codes | Header, theme |
| 8 | **Details**: location, RERA no., phone, WhatsApp, email, site address, Google Maps pin, acres, total villas, amenities, specifications | Text | Everywhere |

For each villa type also send: built-up area (sq.ft), bedrooms, floors, and 3–5 highlight points.

## How to send

- **Small files (images, PDFs, spreadsheet):** attach them in this chat, or upload to the
  GitHub repo into `public/media/` (GitHub website → Add file → Upload files; max 25 MB per file).
- **Videos and large files:** upload to **YouTube (unlisted)** and send the links — this is also
  the fastest way to play them on the website. Or share a Google Drive folder link.
- **Villa tours:** if they are hosted online (Matterport, Kuula, etc.) just send the link —
  it plugs straight in.

## Exterior / community tour

The community is still under construction, so there is no outdoor tour yet. Options:
1. Use the drone/walkthrough video on the home page now (ready as soon as you send it).
2. Later: 360° exterior renders from the architect's 3D model, or a 360° drone shoot
   once construction is further along — a "Community Tour" page will be added then.

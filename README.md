# Aero Villas Community

Virtual experience website for the Aero Villas community: 360° exterior & interior tours, interactive master plan with villa availability, and enquiries.

See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the full plan and the asset checklist.

## Run locally

```bash
npm install
npm run dev   # http://localhost:3000
```

Content lives in `src/data/project.ts` and `src/data/plots.ts`; media in `public/media/`.
What to send for the real content: [docs/SEND_FILES.md](docs/SEND_FILES.md).

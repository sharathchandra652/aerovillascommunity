AERO VILLAS - OFFLINE PREVIEW
=============================

Open the full Aero Villas website on a laptop with no internet connection.

WINDOWS
  Double-click  "Start Aero Villas (Windows).bat"
  The site opens in your browser. Keep the black window open while browsing;
  close it when you are done.
  If Windows shows "Windows protected your PC", click "More info" > "Run anyway".

MAC
  Double-click  "Start Aero Villas (Mac).command"
  If macOS says it can't be opened: right-click the file > Open > Open.
  The first time, macOS may offer to install Python 3 (Command Line Tools) -
  accept, then double-click the file again.

WORKS OFFLINE
  Home page, 3D Digi Tour, Exterior walkthrough, Master plan,
  Villa pages (images), Gallery.

NEEDS INTERNET
  The housing.com villa tours, WhatsApp / enquiry, and the location map -
  these come from other websites.

Do not move files out of this folder - the "site" folder must stay next to
the start files.
